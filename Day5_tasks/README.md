# React Admin CRUD Module

A feature-rich, responsive Admin Dashboard built with React, Vite, Tailwind CSS, and custom hooks.

## ✨ Features

- **Full CRUD Operations:** Create, read, update, and delete entries for Users, Products, and Tasks.
- **Optimistic UI Updates & Rollbacks:** Instant local mutations with automated rollbacks upon simulated API failures.
- **Persistent Storage:** Seamless synchronization with `localStorage` for all records, filters, and preferences.
- **Theme Customization:** Toggle instantly between light and dark visual themes.
- **Advanced Filtering:** Instant global search and record filtering across categories.
- **Modal Confirmations:** Safe-guarded delete prompts and validation states.

## 🚀 Tech Stack

- **React** (v18+)
- **Vite**
- **Tailwind CSS** (v4)
- **Context API & Reducer Pattern**
